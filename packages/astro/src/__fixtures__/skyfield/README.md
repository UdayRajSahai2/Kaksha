# Skyfield reference states

`skyfield-reference.json` is generated by [`notebooks/skyfield_crosscheck.py`](../../../../../notebooks/skyfield_crosscheck.py) (Skyfield and python-sgp4, pinned in `notebooks/pyproject.toml`) and read by `skyfield.crosscheck.test.ts`. Regenerate with `uv run python skyfield_crosscheck.py` in `notebooks/`, then run `pnpm test -u` and review the change to `docs/validation/skyfield-crosscheck.md`.

Inputs are the SGP4 verification element sets (MIT, see `../sgp4-verification`); the outputs are computed values, not third-party data.
